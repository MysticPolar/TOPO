# Owlpo App Assets

Prepared separate files for coding the Owlpo main screen.

## Folders
- `illustrations/`: weather lighthouse banner PNG
- `avatars/`: owl avatars in 256px, plus 64px/128px versions
- `book-covers/`: sample featured book cover
- `seals/`: wax seal assets
- `icons/`: production-ready SVG line icons
- `tokens/`: CSS and JSON color tokens

## Notes
Generated image assets may still need final designer polish before App Store-level production. The SVG icons are clean code assets and ready for implementation.
